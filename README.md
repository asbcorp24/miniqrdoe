# MiniQRDOE — журнал маршрутных карт

Мобильное приложение PHP 8.1+ / SQLite. Учёт операций изготовления деталей, станков, работников, групп и отчётов. Все файлы сайта размещены локально — нет CDN, Composer и внешних библиотек.

## Установка
1. Включить PHP-модуль pdo_sqlite.
2. Дать PHP права записи в каталог var/ (создаётся при первом запросе).
3. Настроить DocumentRoot виртуального сайта на каталог public/ — это самый безопасный вариант. Если корень сайта совпадает с корнем репозитория, включить mod_rewrite и AllowOverride All для корневого .htaccess.
4. Открыть сайт. Таблицы SQLite создаются автоматически.
5. В справочниках создать работников и станки, записать уникальный код каждой записи в наклейку QR. Создать группы деталей.
6. Использовать HTTPS на телефоне, иначе доступ к камере запрещён.

Локальный запуск: php -S localhost:8080 -t public (требуется pdo_sqlite).

## Сценарий
Сотрудник сканирует QR станка, QR работника, выбирает группу и нажимает «Начал работу». Сервер назначает уникальный номер детали и время начала (UTC). После «Закончил» сервер записывает окончание, длительность и увеличивает количество готовых деталей. Когда изготовлены все детали, группа закрывается. Операции атомарны, используется SQLite BEGIN IMMEDIATE.

Группа хранит время приёма, плановый срок изготовления, количество, число готовых деталей и фактическое время закрытия. Один рабочий не может вести две активные операции одновременно. Номера деталей не переиспользуются.

## Аналитика
Фильтр по датам; число операций, готовых деталей, активных работ, суммарная длительность, показатели по работникам и станкам, распределение по дням, CSV-экспорт для Excel.

## Ограничения первой версии
- Нет встроенной аутентификации и ролей. **Не размещайте приложение в открытом интернете без защиты VPN или HTTP-аутентификации на сервере.** QR-код не является подтверждением личности.
- QR-сканер использует встроенный BarcodeDetector браузера, который есть не везде. При несовместимости — ручной выбор. Для полной поддержки мобильных браузеров нужна локально размещённая JS/WASM-библиотека декодирования.
- Нет интерфейса коррекции брака, отмены, резервных копий, печати QR, сложных KPI и аудита изменений.
- Временные метки сохраняются в UTC. До промышленной эксплуатации необходимо проверить интерфейс и базу на целевом сервере и телефонах.
